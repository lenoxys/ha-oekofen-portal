# Variable reference

Every variable the portal's web app knows, grouped by function, generated by `scripts/build_docs.py` from the portal's public configuration file. See [Parameters and nomenclature](parameters.md) for how to read the names.

- **Variable**: the portal name, after `CAPPL:LOCAL.` (or `CAPPL:` for `FA[n]`); `[n]` is the instance (0 for the first circuit). `L_` names are measurements and states, read only; the others are settings.
- **Name**: the English name the integration gives it (words it has no translation for are left in German).
- **Local JSON**: the field of the controller's local interface, when it has one (`N` = n + 1).
- **Type**: `number`, `options` (an index into a list of states), `time` / `simpletime` (HHMM) or `comfortzeit` (a schedule slot); empty when the portal only reads it.
- **Integration**: *30 s* polled often (otherwise every 5 min), *set* writable from Home Assistant, *set locally* written through the local interface, *panel* / *solar boost* the short name used there.
