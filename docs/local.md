# Local JSON interface

The fields of the controller's local interface (`http://<controller>:4321/<password>/all?`), generated by `scripts/build_docs.py` from the controller's own description, read on a Touch with JSON interface V4.00b. A plant with more circuits has `hk2`, `ww2`… with the same fields; groups this plant does not have (`pe` pellet boilers, `circ` circulation pumps, `se`, `thirdparty`, `power`, `stirling`) are not listed. See [Parameters and nomenclature](parameters.md) for how to read and write them.

- **Factor**: the real value is the raw value times the factor (`225` × 0.1 = 22.5 °C); writes use the raw value.
- **Range**: the bounds the controller accepts for a setting.
- **Type**: `options` is an index into a list of states (in `all?`, in the controller's language); `text` a string; `status` a bit field.
- **Access**: `L_` fields are read only.
- **Portal**: the same variable on the portal, when the integration pairs them ([variable reference](variables.md)).
